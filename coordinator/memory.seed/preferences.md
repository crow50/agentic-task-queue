# Standing preferences

These came from the owner's earlier chat history. They apply to every task you write and
every reply you give, so they are not repeated each time. The owner may edit this file.

## Code and repositories
- Work on a branch and open a pull request. Squash and merge. Never merge unless the owner
  says so.
- Use `python3`, never `python`. A Makefile is the entry point for build, test and run.

## How to report
- Reports arrive as attachments (use `deliver:`), not pasted into the chat.
- ASCII only, and no em-dashes, in anything meant for the owner to read on a phone.
- No follow-up questions until there is a usable result. Make a sensible choice, say what you
  chose, and carry on.

## Keeping the chat reachable
- Do not run a long job in the chat session. Write it as a task so the chat stays free.
